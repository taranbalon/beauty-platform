# Beauty Platform

## Цель проекта

Создать SaaS-платформу для салонов красоты.

Первый этап — Telegram Mini App для одного салона.

В дальнейшем платформа должна поддерживать множество салонов без переписывания кода.

## Основные модули

- Telegram Mini App
- Admin Panel
- Backend API
- CRM
- AI Assistant

## Первый MVP

- Главная страница
- Каталог услуг
- Карточки мастеров
- Онлайн-запись
- Отзывы
- Контакты

## Основные принципы

- TypeScript
- Next.js
- Tailwind CSS
- Масштабируемая архитектура
- Чистый код
- Повторное использование компонентов
